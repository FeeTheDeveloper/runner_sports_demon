## What this repository demonstrates

A governed sports-research control plane with explicit data contracts, approval boundaries, deterministic validation, and separation from the public Runner Sports presentation layer.

## Fee The Developer delivery

- Provider and data-contract boundaries
- Dry-run and publish-control mechanisms
- Testable jobs, dashboards, and validation paths
- Audit-conscious system design for sports research

## Truth boundary

This case study does not claim a calibrated model, profitable edge, automated wagering, active public publishing, or current provider health. Market-implied data is not an independent Runner Sports forecast, and validation output is not authorization to mutate an external system.

## Verification

Run the repository build, test, contract, and system-validation scripts. Keep publishing disabled unless a separately authorized, current provider workflow passes its approval and audit requirements.
