# Dashboard observation and execution

This is an observation checklist, not a fixed click-path. Use current official help and observed controls. Do not claim Scenebuilder, Flow Agent, ingredients or export features exist in the selected account until seen.

Prepare mode: deliver prompts, targets and a conditional navigation checklist without opening or assuming a signed-in session.
Drive mode: use only an available authorized browser or supported connector for a user-requested operation. Follow that tool's account-selection and authentication rules; do not bypass access checks.

1. Confirm entity, account, project and visibility; record available controls.
2. Observe selected model, output count, supported ratio/duration and credit balance.
3. Read generation cost; compare the bounded task against existing owner authorization. Ask only for missing authorization required for the action.
4. Create or select the authorized campaign project. Add approved nonconfidential assets as directed. Configure observed settings and paste one shot prompt.
5. Generate within the authorized ceiling. Observe completion and review before iterating. On timeout inspect existing results before retrying.
6. Assemble through observed editing controls if available; otherwise export verified clips for an editor handoff. Do not imply external assembly is native.
7. Add approved soundtrack, logo, captions and CTA in a suitable authorized editor. Review final ratio, duration, copy and audio.
8. Export using observed options and verify the resulting file/link. Publishing, scheduling and sharing require their own applicable authorization.
9. Report project/output evidence, credits actually shown, review results and remaining work.

For sign-in, MFA, CAPTCHA or account permission walls, follow the browser tool's supported handoff. Do not request secrets in chat. Use an observed in-app assistant when useful; it cannot grant rights or authorize spending. Keep confidential media and personal/customer records out of campaign prompts.
