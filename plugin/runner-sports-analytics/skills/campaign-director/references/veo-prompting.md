# Video and still prompt framework

Use current official Google documentation for factual feature advice and the observed UI for account-specific availability. Do not freeze model versions, durations, prices or controls in this reference.

Plan each shot as one subject, action and camera idea. Keep garment colorway, logo geometry, fit, lighting and environment consistent using approved reference assets where the interface supports them.

Still prompt fields: subject; exact garment and colorway; pose/action; environment; light; camera/framing; safe areas for later overlays; continuity anchor.
Video prompt fields: approved ingredient; subject/action; camera movement; light; pacing; target duration and ratio subject to UI support; continuity; audio; exclusions.
Example: “Portrait streetwear campaign. An adult model wearing the approved sage hoodie walks toward camera in soft evening light. Slow backward tracking, fabric movement visible, centered framing with clean upper space. Ambient footsteps only, no music, no on-screen text, no subtitles, no invented logos.”
Keep real artwork as an approved ingredient or add it in post; assess drift before calling a branded garment faithful. Do not claim a generated depiction is a manufactured sample.

For a multi-shot cut, request ambient effects without music and add one continuous soundtrack in post. Treat spoken dialogue as a separate verified task. Record prompt, observed settings, attempt, output, review notes and approval state.
Review continuity, anatomy, garment seams/fit, print or embroidery placement, camera artifacts, logo drift and crop safety. Revise one meaningful variable at a time. A still prompt is a brief until an image is rendered.
